# Отступления от оригинала — закрытые/принятые

Решение принято и реализовано — работы не требуют. Рабочий список — в [deviations.md](deviations.md).

Ни одно закрытое отступление **не является потолком платформы**: NeoForge 26.x умеет и оригинальное
поведение (`registerSimpleBlockItem`, `registerSimpleItem`, blockstate-свойства вместо меты, data-компоненты
и attachments вместо NBT, декларативные `effects.minecraft:attributes` в JSON зачарований, датапак-перезапись).
Единственное внешнее ограничение в проекте — жёсткий список хоста для распространения скверны, и оно в
рабочем списке (⛔). Здесь различия — это либо та же функциональность в современной форме, либо выбор автора.

## ✅ Готово по этапам

- **Чернила** (M17) — umbral_rose → 2 black_dye крафтом.
- **Скверный плод** (M17) — дроп с листвы, шанс 2%.
- **gluttony 0/1/2** (M17) — торт и кольцо оба под `gluttonyMode() != 1`.
- **Теги осколков** (M17) — отдельные id; тег не нужен, рецепты ссылаются на id.
- **Рендерер клетки** (M16) — extractEntity/submit; проверено в runClient.
- **Плавка бревна** (M9) — taint_log → taint_coal, опыт 0.15.

## ♻️ Та же функциональность, современная идиома (форма изменилась, возможности — нет)

- **Кристалл моба** — компонент `mob_id` вместо мета 0/1: тип + валидация + синхронизация, строже меты.
- **Скверный камень** — два блока; тот же «0/1» даёт и одно `BooleanProperty` (выбор формы, не ограничение).
- **`enchanting = false`** — глушится датапаком/реестром; остаточная запись в реестре не даёт игрового эффекта (в 1.7.10 хардкод-зачарования вообще нельзя было снять конфигом).
- **tainted update** — `TaintBiomes.isTainted` вместо числового biomeID (в 26.x их нет, это предикат/Holder).
- **profane update** — компонент `PROFANE_CONTRACT` (или attachment) вместо NBT.
- **Стоимость зачарований** — min/max в JSON вместо enchantability (на столе недоступны и там, и там).

## ⚖️ Принято решением (осознанная замена или эквивалент; платформа это умеет)

- **Портал** — obsidian как ингредиент. Ванильный `nether_portal` не наш и без `BlockItem`; но мод-портал со своим айтемом (`registerSimpleBlockItem`) или предмет-активатор — доступны. Obsidian — выбор, не потолок.
- **Банки клетки** — обычный `warded_jar`. Свой `empty_jar` регистрируется в строку (`registerSimpleItem`); не стали — выбор.
- **Бонус wrath** — `ATTACK_DAMAGE` + зачарования, числа в границах теста. Точный «+1» даёт `ADD_VALUE` или декларативный `effects.minecraft:attributes` в JSON зачарования — тоже доступно.
- **profaned стержень** — bedrock + программная конверсия (совпадает с оригиналом); реальный `ProfanedRodItem` регистрируется тривиально.
- **Метки сущностей** — `entityCopy` (merge) из патча 0002.
- **ItemMobCrystal** — портирован как ядро (нужен клетке).
- **Боссы для pride** — явные типы вместо `IBossDisplayData`.
- **Картинки исследований** — namespace `forbiddenmagic:`.
- **TT-интеграция** — reflection по публичному API (TT под ARR, не в classpath).
- **Cluster / Impact / Voidtouched** — вместе с морф-инструментами.
- **Ремонт инструментов** — компонент `REPAIRABLE` с энви-осколком.
- **Рецепты инструментов** — meta → хост-предметы (`enchanted_fabric`, `silverwood_log`).
- **Рецепт Voidtouched** — `void_seed`.
- **Арк. торт: восстановление** — срез на random tick, как в оригинале.
- **Арк. торт: дроп** — `noLootTable()`, как в оригинале.
- **Арк. торт при `gluttony = 1`** — рецепт не регистрируется, как в оригинале.
- **Последний кусок торта** — бокс 14/16 (оригинальный 12/12 вырожден).
- **Импринт кристалла** — убийство вилкой в основной руке, как в оригинале.
- **Импринт (карта мобов)** — современные id вместо имён 1.7.10.
- **Стержни: регистрация** — `WandRegistry.registerRod` (публичный add-on хук).
