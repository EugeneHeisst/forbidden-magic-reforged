# Отступления от оригинала — закрытые/принятые

Решение принято и реализовано — работы не требуют. Рабочий список — в [deviations.md](deviations.md).
Формат: **что** — как в порте (почему).

## ✅ Готово по этапам

- **Чернила** (M17) — umbral_rose → 2 black_dye крафтом.
- **Скверный плод** (M17) — дроп с листвы, шанс 2%.
- **gluttony 0/1/2** (M17) — торт и кольцо оба под `gluttonyMode() != 1`.
- **Теги осколков** (M17) — отдельные id; тег не нужен, рецепты ссылаются на id.
- **Рендерер клетки** (M16) — extractEntity/submit; проверено в runClient.
- **Плавка бревна** (M9) — taint_log → taint_coal, опыт 0.15.

## 🔒 Вынужденно платформой (26.3 не умеет как 1.7.10)

- **Портал** — obsidian вместо предмета портала (у блока нет предметной формы).
- **Иконка HELLFIRE** — flint_and_steel (у огня нет предметной формы).
- **Скверный камень** — два блока вместо мета 0/1 (нет мета-предметов).
- **Кристалл моба** — компонент `mob_id` вместо мета 0/1.
- **`enchanting = false`** — JSON остаётся в реестре, глушатся эффекты/рецепты (датапак-запись не снять конфигом).
- **Бонус wrath** — `ATTACK_DAMAGE - 1` + зачарования (attribute API не даёт исходный modifier один-в-один).
- **Стоимость зачарований** — min/max в JSON вместо enchantability (на столе недоступны и там, и там).
- **Банки клетки** — обычный `warded_jar` (в хосте нет пустой банки).
- **tainted update** — `TaintBiomes.isTainted` вместо числового biomeID.
- **profane update** — компонент `PROFANE_CONTRACT` вместо NBT; программный добор исследования убран (`ROD_profane` и так гейтит крафт).
- **profaned стержень** — bedrock + программная конверсия (отдельного предмета нет).

## ⚖️ Принято решением (эквивалент, иначе)

- **Метки сущностей** — `entityCopy` (merge) из патча 0002.
- **ItemMobCrystal** — портирован как ядро (нужен клетке).
- **Боссы для pride** — явные типы вместо `IBossDisplayData`.
- **Картинки исследований** — namespace `forbiddenmagic:`.
- **TT-интеграция** — reflection по публичному API (TT под ARR, не в classpath).
- **Cluster / Impact / Voidtouched** — вместе с морф-инструментами.
- **Ремонт инструментов** — компонент `REPAIRABLE` с энви-осколком.
- **Рецепты инструментов** — meta → хост-предметы (`enchanted_fabric`, `silverwood_log`).
- **Рецепт Voidtouched** — `void_seed`.
- **Арк. торт: восстановление** — срез возвращается на random tick, как в оригинале.
- **Арк. торт: дроп** — `noLootTable()`, как в оригинале.
- **Арк. торт при `gluttony = 1`** — рецепт не регистрируется, как в оригинале.
- **Последний кусок торта** — бокс 14/16 (оригинальный 12/12 вырожден).
- **Импринт кристалла** — убийство вилкой в основной руке, как в оригинале.
- **Импринт (карта мобов)** — современные id вместо имён 1.7.10.
- **Стержни: регистрация** — `WandRegistry.registerRod` (публичный add-on хук).
