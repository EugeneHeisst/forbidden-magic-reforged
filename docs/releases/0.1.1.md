Unofficial port of Forbidden Magic 0.574 (Minecraft 1.7.10) for Thaumcraft 4: Reforged 1.1.2 on Minecraft 26.3 / NeoForge 26.3. Requires Java 25 and Thaumcraft 4: Reforged 1.1.2 or newer. Install on both client and server.

## Fixed since 0.1.0

- The Russian localization of the Alchemical wand cap and the Equivalent wand rod was missing, so the creative tab showed raw translation keys. English names now match the original wording.
- The Alchemical cap and Taint Coal icons were copied without their animation metadata, so the client stretched three frames into one inventory slot. The animations play again.
- The Equivalent rod used its 96x96 wand model texture as an item icon. 1.7.10 had no item icon for that component; the port now ships a 16x16 icon made from the original model artwork.

## Host notes

- A stock Thaumcraft 4: Reforged 1.1.2 host is enough to run the port.
- Scanning the Nether Portal keeps the original NETHER 4 assignment only on a host built with the local patch `patches/0001-block-aspect-targets.patch`. Without it the portal block has no direct aspect and the mod logs that block aspect targets are unavailable.

## Known limits

Client-side visuals for the morph tool phase tint, the neutronium wand family and the per-face tainted log textures are implemented and covered by data tests, but have not been confirmed in a running client yet.
