# Forbidden Magic: Reforged 0.1.0-beta.1

First experimental beta for Minecraft 26.3 / NeoForge 26.3, Java 25.

This release is for early testing. Core parity is not declared complete, and it is not a promise of compatibility with unmodified Thaumcraft installations.

## Important compatibility notice

This addon currently depends on Thaumcraft 4: Reforged APIs and block-scan registry changes that are not yet present in the unmodified published host release. The beta is built and tested against the upstream host commit pinned in `host.sha`, with this repository's compatibility patches applied by `python tools/prepare_host.py`.

**Do not assume this JAR will work with the stock published Thaumcraft 4: Reforged JAR.** The host JAR is not included because its repository specifies All Rights Reserved. The local host build is only a development/test prerequisite until the required upstream changes are published.

## Verification performed for this release

The release is published only if its workflow succeeds at all of the following:

- Build and publish the pinned, patched host into the local Maven repository.
- Build the add-on and verify JAR provenance.
- Run the complete required GameTest suite with `no_lust=false`.
- Run the complete required GameTest suite with `no_lust=true`.

Automated headless tests do not replace the remaining manual client and gameplay checks. See [roadmap](../../blob/main/docs/roadmap.md), [fidelity ledger](../../blob/main/docs/fidelity.md), and [verification status](../../blob/main/docs/verification.md).

## Requirements

- Minecraft 26.3
- NeoForge 26.3.0.57-beta
- Java 25
- A compatible, locally patched Thaumcraft 4: Reforged 1.2 host build as described above

Back up worlds before testing prerelease builds and report issues with the game version, host commit/patch set, configuration (especially `no_lust`), and relevant logs.
