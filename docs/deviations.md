# Отступления от оригинала — рабочее

Что ещё отличается от оригинала и требует решения. Формат: **что** — чем отличается → что делать.
Принятые и закрытые — в [deviations-closed.md](deviations-closed.md).

## 🔧 Можно делать

- **Циклирование эссенции клетки** — вилка должна переключать источник (аспект моба / ira / desidia), сейчас авто-приоритет. → *решить: вернуть переключение или оставить авто?*
- **spork-иконка** — оригинал меняет и икону (`spork.png`), не только имя. → скопировать текстуру, переключать модель по флагу.
- **Осколок lust → despair** — при `no_lust` оригинал даёт имя `despair` + VOID-тег. → условное имя + тег.
- **Corrupting: taint в пуле** — сейчас `gluttony` вместо `taint`. → вернуть `taint` (дерево есть с M5).
- **Череподрать: скорость** — оригинал жёстко `getDigSpeed=1.0`, сейчас из material. → кастомный item с `getDestroySpeed()=1.0`.
- **Центр клетки → arcane_stone** — оригинал `blockCosmeticSolid` meta4, сейчас `thaumium_block`. → вернуть `thaumcraft:arcane_stone` (есть в хосте).
- **Теги FM-блоков/ресурсов** — отложены, а §5.1 закрыт. → добавить `c:wood` и т.п.
- **Taint-осколок с tainted-блоков** — не подключён. → формула дропа из оригинального `FMEventHandler`.
- **Бонемил Куста Теней** — `spreadFlowers` на костную муку. → `BonemealableBlock` на `umbral_rose_bush`.
- **Цвет фазы морф-инструмента** — оверлей красится в цвет фазы. → item-tint provider.
- **Impact: выбор плоскости** — сторона из рейкаста, сейчас ось взгляда. → `hitResult.getDirection()`.
- **Переключение фаз** — оригинал требует NBT (первое зачарование), сейчас всегда. → вернуть гейт.
- **Боковые текстуры бревна** — gross-вариант 25% потерян. → blockstate-варианты / случайная модель.
