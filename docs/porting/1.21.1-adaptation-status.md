# Статус адаптации Minecraft 1.21.1

Текущая сборка использует Minecraft 1.21.1, Java 21, NeoForge 21.1.256+ и Thaumcraft UNOFFICIAL PORT (`tc4modern >= 0.17.191`). Ветка Minecraft 26.3 и прежняя схема патчинга другого хоста не участвуют в актуальной сборке.

Архитектура и происхождение переноса: [техническое описание](../design/upstream-port-design.md). Реализованные интеграции, отличия и проверки: [совместимость с TC4Modern](../tc4modern-compatibility.md).

## Сборка

```sh
python tools/prepare_dependencies.py
./gradlew clean build
python tools/check_provenance.py
```

Для тестового набора зависимостей:

```sh
python tools/prepare_dependencies.py --test-pack
./gradlew -PcompatTest -PcompatPack=deps/test-pack runGameTestServer
```

Все скачиваемые зависимости закреплены версиями и SHA-256. `-Ptc4Jar` может выбрать отдельную локальную сборку хоста. Тестовые классы и классы хоста не включаются в итоговый JAR аддона.
