# 1.21.1 adaptation status

## Verified build baseline

- Target: Minecraft 1.21.1 / NeoForge 21.1.256 / Java 21.
- Thaumcraft target source: `mc/1.21.1`, pinned by `host.sha`.
- Host is patched in a disposable `host/` checkout and published to the local Maven repository before add-on compilation.
- The target-specific aspect patch enables an ordered add-on aspect registry while retaining all 48 built-in aspects and their order.
- Forbidden Magic registers seven sin aspects (`luxuria`, `infernus`, `superbia`, `gula`, `invidia`, `desidia`, `ira`) and has GameTests for the registry, config gate and serialization.
- The aspect-only build and GameTests passed in GitHub Actions before the broader content files were introduced.

## Why the 26.3 sources are staged

The main content sources copied from the `dev` line use Minecraft/NeoForge APIs introduced after 1.21.1 (new item tooltip contexts, dynamic model APIs, newer rendering state types, newer block growth interfaces, newer entity NBT input/output and loot/fuel types). A global package rename is not enough to backport those APIs.

Until each feature slice has been ported and compiled against the pinned host, the original/newer sources live under `porting/26.3-staging/src/main/java/` instead of the compiled source set. They are retained as a reference, not represented as 1.21.1-compatible code.

## Next porting slices

1. Simple items and block registrations, with 1.21.1 tooltip and block-growth APIs.
2. Recipes, aspects on items/entities, research and wand integrations, each with tests.
3. Wrath Cage persistence/entity spawning and all custom items.
4. Client models, conditional item models, tint sources and renderer, rewritten for 1.21.1 rendering APIs.
5. Run `./gradlew build`, `./gradlew runGameTestServer`, and a manual `runClient` visual pass.

A successful aspect-only CI run proves the compatibility foundation; it does not mean all original Forbidden Magic content is ported.
