# 1.21.1 target: shared resource intake

This is the first version-agnostic resource slice copied from `main` at `a99cffd`.

## Transferred

- 85 existing texture/animation files under `src/main/resources/assets/forbiddenmagic/textures/`.
- English and Russian localization JSON from the active line.
- The English/Russian TOML localization source data.
- `data/id_map.json`, the old-to-current identifier map.

## Build target

The Gradle scaffold now targets Minecraft 1.21.1:

- Java toolchain: 21
- Minecraft: 1.21.1
- NeoForge: 21.1.264
- ModDevGradle: 2.0.148
- Gradle wrapper: 9.2.1
- Parchment mappings: 1.21.1 / 2024.11.17
- TerraBlender: 1.21.1-4.1.0.1
- JEI: 19.57.0.451
- Thaumcraft dependency version: 1.1

These are configuration targets, not evidence that the current Java source builds against 1.21.1.

## Deliberately not transferred

- Java implementation and host patches: the active line targets Thaumcraft 4: Reforged / Minecraft 26.3, and its APIs are not assumed compatible with 1.21.1.
- Generated blockstates and model JSON: the active line's resource layout may use post-1.21.1 item model formats.
- Item/block tags that reference registrations not yet present in this branch.
- CI/workflow configuration or claims of test coverage.

## Known blockers outside the Gradle scaffold

- Existing Java sources still use API types and methods from the 26.3 line (for example `net.minecraft.resources.Identifier` and the custom `thaumcraft.aspect.AddonAspects` API), neither of which can be assumed to exist on upstream `mc/1.21.1`.
- `tools/prepare_host.py`, `host.sha`, and the current host patches are still based on the 26.3 line. The local Thaumcraft 1.21.1 artifact build/publish flow must be separated before `gradlew build` can be treated as reproducible.

The Gradle wrapper/plugin/dependency versions and metadata have been set for 1.21.1, but a Minecraft 1.21.1 build and in-game validation have not been run.
