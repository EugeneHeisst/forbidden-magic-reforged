# Адаптация к TC4Modern — 2026-10-27

Цель: Minecraft 1.21.1, NeoForge 21.1.256, Java 21. Исходная ветка — `MxxFoxx2/forbidden-magic-reforged:1.21.1`. Ветка автора `main` для 26.3 не используется.

## Что перенесено

| Подсистема | Интеграция |
| --- | --- |
| Аспекты | Настоящие `thaumcraft.api.aspects.Aspect`, а не второй независимый реестр. Семь аспектов Forbidden Magic видны сканированию, знаниям, рецептам и эссенции. `no_lust` исключает Luxuria из регистрации. |
| Исследования | Отдельная вкладка FORBIDDEN в родном Таумономиконе, исходные страницы, родители, скрытые открытия и искажение. |
| Рецепты | `TC4Addons` для верстака, тигля и наполнения. Зачарование наполнением включено в родной список и проверяет собственное исследование FM. |
| Жезлы | Родные карты стержней и наконечников, компоненты составных жезлов, перезарядка, расход и ёмкость vis. Отдельный серверный тик для эффектов стержней FM. Текстуры подставляются в родной рендерер. |
| Фокус | Blink использует родную систему фокусов и улучшений; Hellfire/Pandemonium зарегистрированы для манипулятора. |
| Украшения | Родные Baubles: кольцо питания и ошейник. Ошейник использует поведение амулета vis хоста. |
| Клетка гнева | Родной `IEssentiaTransport`, синхронизация и NBT 1.21.1. Зарядка от банок/труб; контейнер доступен адаптерам Thaumic Energistics и очкам откровения. Извлечение из клетки запрещено, как в исходной реализации. |
| Thaumic Tinkerer | Восемь чар в родном каталоге затрат. Размер сетевой синхронизации и кнопок увеличивается вместе с каталогом; дополнительные варианты доступны на страницах по 16 через колесо мыши. |

Обязательна только зависимость `tc4modern >= 0.17.191`. Остальные шесть портов не становятся обязательными. Работа с IC2/ASP/EMT/Gravi означает совместный запуск; новых энергетических механик этот перенос не изобретает.

## Необходимые отличия интеграции

- Чужие Java-пакеты `thaumcraft.aspect`, `.wand`, `.crafting` и прочие заменены собственными адаптерами в `dev.visfox.forbiddenreforged.compat`. В JAR нет классов или ресурсов хоста. Файлы репозитория Thaumcraft не меняются; access transformer открывает только видимость класса конфигурации в рантайме.
- Родной `WandData.add` принимает целые vis; реальные сотые доли vis передаются через `VisStorage.addRealVis`. Отдельные пути не смешиваются. Материалы инструментов берутся из настоящих уровней Elemental/Thaumium хоста.
- Бесформенные магические рецепты представлены сеткой 3×3 с пустыми ячейками: конструктор `ArcanePattern` не допускает ширину 6. Набор ингредиентов и стоимость сохранены.
- Ключи `ROD_TAINTED`/`ROD_INFERNAL` сопоставлены реальным исследованиям `ROD_tainted`/`ROD_infernal`, чтобы матрица не требовала несуществующего исследования. Ключи страниц зачарования используют префикс `InfEnchFM`, который поддерживает родной рендерер страниц.
- В качестве иконки Hellfire используется fire charge: у блока `minecraft:fire` нет зарегистрированного предмета в 1.21.1.
- Модели кусочков магического торта получили ссылку `particle: #side`. Сами текстуры сторон уже существовали; отсутствовала именно текстура частиц.
- Обобщённые предметы-инструменты получили зачаровываемость соответствующего материала. Без неё Morph Tools отвергались нативным столом Tinkerer, а Voidtouched нельзя было выбрать для них.
- Нативный контракт труб возвращает фактически принятое количество. Клетка не принимает посторонний аспект и не переполняется сверх 64 единиц на запас; `addToContainer` возвращает остаток.

## Проверки и границы

14 нативных GameTests проверяют загрузку набора, реальные аспекты и теги, родителей исследований/иконки, ингредиенты наполнения, сопоставление магических и тигельных рецептов, жезлы и перезарядку, регистрацию чар, NBT клетки, Baubles/чернильницы, улучшения фокуса, запрет наполнения без исследования, все восемь кнопок Tinkerer за прежним пределом 40, передачу эссенции из настоящей банки и предел ёмкости.

Отдельный скрытый клиент проверяет 92 варианта предметов/жезлов и наличие всех восьми FM-чар в настоящем интерфейсе Tinkerer. Скриншоты и журналы локально: `../compat-test/forbidden-magic-audit`. Проверяется обычный рендерер; это не тест производительности GPU и не полный игровой прогон каждого эффекта или рецепта наполнения.

Нет автоматического переноса сохранений из Thaumcraft 4: Reforged. Сторонние интеграции Ars Magica из upstream не проверяются этим набором. Исторические спек/патчи другого хоста сохранены для происхождения проекта, но в сборке не применяются.

Sodium и Iris не поддерживаются: с ними возможны визуальные баги.

## Addon aspect icons (0.1.3)

Requires TC4Modern 0.17.191: inventory scanning, the thaumometer, goggles and the deconstruction table now use each registered aspect's own texture identifier. Earlier host versions incorrectly looked for addon icons in the tc4modern namespace. All seven original icons remain in forbiddenmagic; no host textures are bundled.

Validation on 2026-10-29: the final TC4Modern 0.17.191 / Tinkerer 0.1.14 / Forbidden Magic 0.1.3 client passes all 60 native regression/resource checks, including native scan rendering of all seven addon icons in inventory, the first-person device and the offhand HUD. The 0.17.190 / 0.1.2 baseline reproduces tinted missing-texture checkerboards despite all seven registered resources existing. All 14 required integration GameTests pass; a subsequent clean release build excludes the audit classes. Evidence and the native harness are in [the host validation report](https://github.com/EugeneHeisst/thaumcraft-port/blob/main/docs/validation/issues-2026-10-29.md).
