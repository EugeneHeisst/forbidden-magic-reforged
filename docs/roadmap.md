```

last checked: 2026-10-25
status at last check: open, ready for review; awaiting upstream maintainer review
```

PR #37 добавляет публичный API регистрации аспектов аддона. До решения владельца хоста продолжаем
работу, которая не требует менять API хоста. CI аддона использует локально подготовленный Thaumcraft
4: Reforged; зелёный CI не доказывает работу с неизменённым upstream-артефактом. Не сливать локальные
патчи хоста в этот репозиторий как будто это часть самого аддона.

Если PR принят: убрать временную зависимость от локальных патчей там, где API заменяет их, затем
проверить чистую сборку/тесты с опубликованным upstream-хостом. Если PR отклонён: изучить замечания
и решить, можно ли безопасно адаптироваться к существующему API; не обходить закрытый API reflection
или mixin без отдельного обоснования.

## Открытые задачи паритета 26.3

1. **Распространение скверны на блоки Forbidden Magic.** Хост `TaintSpread.isTaintBlock` использует
   фиксированный набор блоков. Нужен публичный hook или расширяемый tag в хосте; не подменять эту
   механику приблизительной логикой в аддоне без теста, что она совпадает с оригиналом.
2. **Aspect scan для Nether Portal.** Оригинал назначает NETHER 4 блоку `minecraft:portal`; текущий
   API аспектов хоста поддерживает item targets, поэтому обсидиан служит прокси. Требуется block/state
   target API в хосте или другое upstream-согласованное решение.
3. **Taintstone recipe.** Второй вариант оригинала использовал `itemResource` meta 11, которого нет в
   современном хосте. Текущий рецепт через тег FM Taint Shard сохранён; точный эквивалент зависит от
   решения, какой современный предмет соответствует старому варианту.
4. **Silverfish / Extreme Hills.** Повышенный шанс осколка сопоставлен с `minecraft:windswept_hills`.
   Это осознанное приближение, а не точное равенство старой карте биомов.
5. **Миграция Mob Crystal.** Компонент хранит namespaced entity ID; старые сохранённые данные не
   мигрируются. Миграция нужна, если проект будет заявлять совместимость с уже существующими мирами.
6. **Witchwood / внешние интеграции.** Blood Magic, Botania, Ars Magica 2 и CoFH не портированы под
   26.3; соответствующий контент остаётся вне scope до появления совместимых зависимостей.

Событие урона `thaumcraft:taint` для Tainted Wand **уже реализовано** и описано в fidelity.md:
три случайных примальных vis по 1 при удержании жезла со скверным стержнем. Это больше не открытая
задача roadmap. Случайный диапазон горения Taint Coal (1–2400) также уже реализован через
`minecraft:uniform` в `context_int_provider/taint_coal_burn.json` и покрыт GameTest
`taint_coal_burn_time_varies_within_original_range`.

## Визуальный гейт — требует реального клиента

- Morph Tools: динамические цвета фаз.
- Creative Wand family: предметы в creative tab, подсказки и модели.
- Tainted Log: вертикальная и обе горизонтальные ориентации.
- Wrath Cage: рендер моба и обновление состояния после смены кристалла.
- Остальные визуальные/боевые пункты, перечисленные в соответствующих срезах [verification.md](verification.md).

Серверный GameTest и headless build не проверяют клиентскую отрисовку. Не отмечать эти пункты
закрытыми без реального `runClient` и записи результата.

## Второй таргет: 1.21.1

- Хост: ветка `mc/1.21.1`, MC 1.21.1, NeoForge 21.1.256, Java 21.
- Отдельные API-патчи (`ResourceLocation` / `javax`), локальный Maven и сборка.
- GameTest использует `@GameTestHolder` / `@GameTest`, не `RegisterGameTestsEvent`.
- Сначала стабилизировать 26.3, затем бэкпортировать на `mc/1.21.1`; не смешивать два таргета в одной сборке.

основном таргете. Пересмотреть список при начале отдельного таргета 1.21.1.
