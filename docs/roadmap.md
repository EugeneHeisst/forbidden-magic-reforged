## Открытые расхождения

Полный список — в [fidelity.md](fidelity.md). Сейчас остаются два пункта:

- событие получения урона `taint` для восполнения vis скверным жезлом — в хосте нет однозначного
  зарегистрированного damage type для безопасного сопоставления;
- биомная карта повышенного шанса изумрудного самородка у чешуйниц использует современный
  `minecraft:windswept_hills` вместо `BiomeGenBase.extremeHills`.

Каждый пункт остаётся задачей, пока он не перенесён или не подтверждён как сознательное отличие.

## Визуальный гейт

Пользователь запускает `runClient` и проверяет рендер скверного бревна, цвета фаз морф-инструмента,
creative-вкладку с creative/profane жезлами и подсказки жезлов. Headless build и GameTests не заменяют
эту проверку.

## Второй таргет: 1.21.1

- Ветка хоста `mc/1.21.1` (`17dd730`): MC 1.21.1, NeoForge 21.1.256, Java 21, TerraBlender `1.21.1-4.1.0.1`,
  JEI `19.57.0.451`, Parchment `2024.11.17`.
- Тот же контент, отдельный набор патчей (`ResourceLocation`/`javax` вместо `Identifier`/`jspecify`),
  отдельный локальный maven и отдельная сборка.
- GameTest — аннотационный (`@GameTestHolder`/`@GameTest`), а не регистрация через `RegisterGameTestsEvent`.
- Апстрим: сначала `main` (26.3), затем `mc/1.21.1`; при бэкпорте автором второй PR не нужен.

## Поддержка сторонних модов

**Поддерживается:** Thaumic Tinkerer Reforged — при его установке стоимость всех восьми FM-зачарований
регистрируется через публичный `EnchantmentManager.data()`, без патча TT и без копирования его кода/ассетов.

**Не поддерживается:** Blood Magic, Botania, Ars Magica 2, CoFH — портов под 26.3 нет. Для 1.21.1 список
пересматривается на этапе второго таргета, обещать заранее нельзя. Ars Nouveau (1.21.1) и Mana and Artifice
(1.20.1) как замена AM2 — отложено: на основном таргете не существует ни один. Подробности и причины —
[fidelity.md](fidelity.md), раздел «Не перенесено».
