## Поддержка: что есть и чего нет

**Поддерживается:** Thaumic Tinkerer Reforged. TT Reforged есть для обеих веток; при его установке
стоимость всех восьми FM-зачарований в энчантере регистрируется через публичный
`EnchantmentManager.data()`, без патча TT и без копирования его кода/ассетов.

**Не поддерживается:** Blood Magic, Botania, Ars Magica 2 и CoFH — для 26.3 портов нет; для 1.21.1
список пересматривается на этапе второго таргета, обещать заранее нельзя. Точный список файлов и
причин — в спеке (§5.2) и `docs/deviations.md`. `plans.txt` оригинального автора не реализуется:
это незавершённый список идей, а не контент.

## Слайс M10: SkullAxe, RidingCrop, Black Dye

Статус на 2026-10-22: **собран**, 49/49 тестов. Добавлены три предмета:

1. **SkullAxe** (топор Череподрать) — sword с `ELEMENTAL_TOOL` material, repairable через thaumium ingot.
   Оригинальный `getDigSpeed(1.0F)` не переопределяется (в MC 26.3 скорость определяется material).

2. **RidingCrop** (верховая плеть) — sword с `THAUMIUM_TOOL` material, repairable через leather.
   Даёт potion effects (Speed, Haste, Strength) при ударе по игрокам/големам. Упрощено — не работает
   на лошадях/свиньях (vanilla классы не найдены в хосте).

3. **Black Dye** (чёрная краска) — красит овец в чёрный при использовании. `EMERALD_FRAGMENT` (meta 0
   из оригинала) уже существовал в порту.

Текстуры скопированы из оригинального FM: `skull_axe.png`, `crop.png` → `riding_crop.png`,
`dye_powder_black.png` → `black_dye.png`.

## Слайс M15: Рабочие стержни жезлов + rod-update

Статус на 2026-10-22: **собран**, 51/51 тестов. Стержни перестали быть инертными предметами и
зарегистрированы в `WandRegistry.registerRod` хоста → из них крафтятся рабочие casting-жезлы, а
`WandItem.inventoryTick` сам зовёт `RodUpdate` (серверная сторона).

Ядерные стержни (без сторонних вариантов): tainted/infernal/profane, значения из оригинала:

| Стержень | capacity | craftCost | update |
|---|---|---|---|
| tainted | 150 | 12 | рефилл прималов <1/10 в скверном биоме (`TaintBiomes.isTainted`) |
| infernal | 150 | 12 | рефилл прималов в Незере + FIRE <1/5 всегда; тушит носителя, снимает wither |
| profane | 50 | 12 | «контракт» 25000: наливает real-vis из пула со sticky-warp, по исчерпании → profaned |
| profaned | 50 | 1000 | burnout-состояние (item `minecraft:bedrock`), конверсия программная |

- `FmComponents.PROFANE_CONTRACT` (`DataComponentType<Integer>`) — аналог оригинального NBT `contract`.
- Модель-текстуры `wand_rod_{tainted,infernal,profane,profaned}.png` скопированы в `textures/model/`.
- `FmWands.register()` вызывается в `FmSetup.commonSetup` после `AddonAspects.init()`.
- Исследования `ROD_tainted/ROD_infernal/ROD_profane` — уже были (M10); они гейтят крафт (`ArcaneWandRecipe`).
- Lang `item.Wand.<tag>.rod` добавлен (en + ru).
- GameTest `wand_rods_register_as_functional_cores`: реестр + capacity + наличие update + сборка жезла.

Вырезано (стороннее): wand caps (все материалы — BM/AM2/Botania), witchwood/blood/mana rods и staff
updates (AM2/BM/Botania). «Ложковилка» = `Config.spork` — alt-имя той же вилки, отдельного предмета нет.

## Слайс M16: модели предметов (найдено через runClient)

Статус на 2026-10-22: **собран**, 51/51 тестов + проверено вживую в клиенте.

`runClient` показал то, чего не видели headless-тесты: 16 предметов M10–M15 грузились с
`Missing item model for location forbiddenmagic:*` — генератор `tools/gen_resources.py` покрывал только
M1–M9. Причина: модели живут в `src/generated/resources` (подключён в сборку, build.gradle:67), а для
новых предметов там не было ни `models/item/*.json`, ни `items/*.json` (новая схема 1.21.4+ требует оба).

- Расширен `ITEM_TEXTURES` (15 простых предметов: вилка, скверный уголь/плод, плеть, black dye, кольцо,
  5 стержней, скверные кирка/лопата, crystalwell/primewell) + двухслойная ветка для `blink_focus`
  (base + ornament).
- Перезапуск генератора: 42 item-определения, заодно generated-lang подтянул ключи M14/M15.

Проверка в клиенте (не на глаз по тестам): **0** предупреждений missing-model; **Клетка Гнева рендерит
моба внутри себя в мире** (путь `WrathCageRenderer`, ранее ни разу не выполнялся в headless);
условная модель `mob_crystal` empty/filled работает. Это закрывает давний пункт «рендерер не смотрели глазами».
