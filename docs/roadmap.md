## Незакрытые требования паритета 26.3

На 2026-10-25 порт нельзя считать полностью паритетным: подтверждены два расхождения, требующих расширения API хоста.

1. **Распознавание блоков скверны хостом.** `TaintSpread.isTaintBlock` использует фиксированный список блоков Thaumcraft и не предоставляет аддону публичного способа добавить собственные блоки Forbidden Magic. Текущий GameTest доказывает только, что FM-taint материалы не заменяются прямым вызовом `spreadFibres` и не попадают в проверенные vanilla-пути преобразования логов/почвы. Он **не** доказывает, что блоки Forbidden Magic распознаются как taint blocks во всех остальных механиках хоста. Нужен публичный hook или расширяемый tag в хосте, затем интеграционные тесты соответствующих путей распространения и преобразования скверны.

2. **Сканирование Nether Portal.** Оригинал назначает NETHER 4 блоку `minecraft:portal`; современный API аспектов хоста поддерживает item targets, поэтому обсидиан используется как прокси. Это меняет объект сканирования. Для точного соответствия нужен API регистрации block/state targets в хосте и тест, подтверждающий аспект именно на портале.

Upstream PR [#37 — public API for add-on aspect registration](https://github.com/notlikethiss/thaumcraft-4-reforged/pull/37) на момент проверки открыт. В описании заявлены регистрация аспектов аддонов и слияние аспектов сущностей, но не block/state aspect targets и не расширение распознавания taint blocks. Его принятие само по себе не закрывает эти два пункта.

## Критерии завершения core parity 26.3

Не объявлять core parity завершённым, пока не выполнены все пункты:

1. Оба API-разрыва выше устранены через публичный API хоста и покрыты интеграционными GameTest; если какое-либо отличие оставляется намеренно, оно остаётся явно обозначенным как незакрытый компромисс, а не как полный паритет.
2. После изменений проходит CI на актуальном HEAD: подготовка закреплённого хоста, сборка/публикация локального артефакта хоста, сборка аддона, `runGameTestServer` с `no_lust=false` и `no_lust=true`, проверка происхождения артефактов. Зафиксировать ссылку на успешный прогон в [verification.md](verification.md).
3. Проведён реальный `runClient`, записаны результаты по цветам Morph Tools, Creative Wand family (модели, подсказки, вкладка и заполнение vis), всем ориентациям Tainted Log, Wrath Cage (рендер и смена кристалла), исследовательским страницам и рецептам. Headless CI этот гейт не заменяет.
4. Поведение, которое невозможно надёжно подтвердить headless-тестами, проверено в игре и занесено в verification: wand damage hooks, реальные дропы осколков, Collar of Pain и действия Riding Crop.
5. Каждое оставшееся отличие от оригинала имеет запись в [fidelity.md](fidelity.md) с доказательством и статусом. Отсутствующие интеграции Blood Magic, Botania, Ars Magica 2 и CoFH считаются отдельным исключённым объёмом; пока они не реализованы, корректно заявлять только core parity без этих интеграций, а не полный паритет всех возможностей оригинала.

## Принятые ограничения и отдельные направления

- **Silverfish / Extreme Hills:** повышенный шанс осколка сопоставлен с `minecraft:windswept_hills`.
  У старого биома нет точного современного аналога; это документированное приближение, а не скрытый баг.
- **Mob Crystal:** текущие предметы хранят namespaced entity ID. Миграция старого NBT из мира Minecraft
  1.7.10 не заявляется: проект не обещает перенос миров между такими версиями игры. Если понадобится
  отдельный конвертер старых миров, это самостоятельная задача, а не блокер текущего порта.
- **Witchwood / внешние интеграции:** Blood Magic, Botania, Ars Magica 2 и CoFH не портированы под
  26.3; соответствующий контент остаётся вне объёма текущего порта до появления совместимых зависимостей.

Событие урона `thaumcraft:taint` для Tainted Wand **уже реализовано** и описано в fidelity.md:
три случайных примальных vis по 1 при удержании жезла со скверным стержнем. Это больше не открытая
задача roadmap.
Распространение волокнистой скверны на материалы Forbidden Magic проверено отдельно. В upstream
`TaintSpread.spreadFibres` меняет только воздух, заменяемые блоки, растительность и листву;
скверные доски и камень не подходят под эти условия. Скверное бревно также исключено из
`minecraft:logs`, так что оно не попадает в отдельный путь превращения брёвен в Crusted Taint.
GameTest `taint_materials_resist_fibrous_taint` фиксирует эти инварианты и прямую попытку spread.
Для узкого требования «FM-материалы не заменяются при spreadFibres» патч хоста не нужен. Это не закрывает отдельный пробел: хост по-прежнему не распознаёт блоки Forbidden Magic в фиксированном предикате taint blocks (см. незакрытые требования выше).
Случайный диапазон горения Taint Coal (1–2400) также уже реализован через
`minecraft:uniform` в `context_int_provider/taint_coal_burn.json` и покрыт GameTest
`taint_coal_burn_time_varies_within_original_range`.

Вторая исходная вариация Taintstone закрыта: `itemResource` meta 11 в Thaumcraft 4.2 — Taint Slime
(современный предмет хоста — `thaumcraft:tainted_goo`). Она добавлена в тег
`forbiddenmagic:taint_ingredients` вместе с FM Taint Shard; GameTest проверяет оба предмета как
валидный центральный ингредиент рецепта.

## Визуальный гейт — требует реального клиента

- Morph Tools: динамические цвета фаз.
- Creative Wand family: предметы в creative tab, подсказки и модели.
- Tainted Log: вертикальная и обе горизонтальные ориентации.
- Wrath Cage: рендер моба и обновление состояния после смены кристалла.
- Остальные визуальные/боевые пункты, перечисленные в соответствующих срезах [verification.md](verification.md).

Серверный GameTest и headless build не проверяют клиентскую отрисовку. Не отмечать эти пункты
закрытыми без реального `runClient` и записи результата.

## Второй таргет: 1.21.1

- Хост: ветка `mc/1.21.1`, MC 1.21.1, NeoForge 21.1.256, Java 21.
- Отдельные API-патчи (`ResourceLocation` / `javax`), локальный Maven и сборка.
- GameTest использует `@GameTestHolder` / `@GameTest`, не `RegisterGameTestsEvent`.
- Сначала стабилизировать 26.3, затем бэкпортировать на `mc/1.21.1`; не смешивать два таргета в одной сборке.
