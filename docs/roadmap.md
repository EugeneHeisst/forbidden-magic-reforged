# Roadmap

Основной таргет — Minecraft 26.3. `main` — каноническая ветка. Completed work и исторические этапы не дублируются здесь: подтверждённые поведения перечислены в [fidelity ledger](fidelity.md), последний CI — в [verification](verification.md).

## Оставшиеся реальные разрывы паритета

1. **Блоки Forbidden Magic в системе скверны.** `TaintSpread.isTaintBlock` использует фиксированный список Thaumcraft и не предоставляет публичного API для добавления блоков аддона. GameTest доказывает, что материалы FM не заменяются в проверенных путях, но не доказывает, что host распознаёт их как taint blocks во всех механиках. Фикс: расширяемый tag/hook в хосте и интеграционные GameTest для распространения и преобразования.
2. **Aspect scan Nether Portal.** Оригинал назначает NETHER 4 блоку `minecraft:portal`; текущий API принимает item targets, поэтому обсидиан используется как прокси. Фикс: добавить в host публичную регистрацию block/state aspect targets, назначить NETHER 4 порталу и покрыть сканирование GameTest.

Открытый [host PR #37](https://github.com/notlikethiss/thaumcraft-4-reforged/pull/37) добавляет регистрацию аспектов аддонов и слияние аспектов сущностей, но на момент последней проверки остаётся Draft и **не** закрывает эти два API-разрыва. До появления API локальные патчи хоста необходимы.

## Незакрытые ручные проверки

- `runClient`: tint Morph Tools, модели/подсказки/creative tab и заполнение vis у creative wand family.
- `runClient`: Tainted Log во всех трёх ориентациях; Wrath Cage render и обновление моба после смены кристалла.
- Реальная игровая проверка hooks урона жезлов, дропов осколков, Collar of Pain и Riding Crop.

Headless CI не заменяет визуальный и игровой гейт.

## Ограничения, не выдаваемые за баги

- Старый Extreme Hills сопоставлен с `minecraft:windswept_hills`; точного аналога нет.
- Mob Crystal хранит современный namespaced entity ID; миграция миров 1.7.10 не заявлена.
- Blood Magic, Botania, Ars Magica 2 и CoFH не поддерживаются на 26.3 из-за отсутствия согласованных совместимых зависимостей. Без них нельзя заявлять полный паритет всех возможностей оригинала.
- 1.21.1 начинается только после закрытия основного гейта 26.3.

## Гейт завершения 26.3

- Оба host API-разрыва устранены или оставлены явно задокументированными как компромиссы.
- Текущий CI зелёный: host prepare/build/publish, build аддона, provenance и GameTests с `no_lust` в обоих режимах.
- Завершён `runClient` и записаны результаты всех пунктов выше.
- Все реальные расхождения остаются в `docs/fidelity.md`; никаких вторых deviation ledgers.
