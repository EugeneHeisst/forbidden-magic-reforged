# Forbidden Magic: Reforged

Неофициальный порт Forbidden Magic 0.574 (Minecraft 1.7.10) на Thaumcraft 4: Reforged (Minecraft 26.3).

## Описание

Порт переносит контент оригинального Forbidden Magic на современный хост: аспекты грехов, осколки, зачарования, инструменты, скверные материалы и растения, кристалл моба, Клетку Гнева и другие предметы.

**Поддерживается:**
- Семь аспектов грехов и таблица меток существ
- Дропы осколков и категория исследований `FORBIDDEN`
- Восемь зачарований с исследованиями и рецептами
- Хамелеоновы инструменты с переключаемыми наборами зачарований
- Скверные материалы, растения и Арканный торт
- Кристалл моба и Клетка Гнева со спавнером
- Вилка дьяволиста и скверный уголь
- Конфиг `no_lust` для отключения контента
- Опциональная интеграция с Thaumic Tinkerer Reforged

**Не поддерживается:**
- Жезлы, фокусы, скруное дерево, житель-еретик — в разработке
- Blood Magic, Botania, Ars Magica 2, CoFH — нет портов под NeoForge 26.3
- Minecraft 1.21.1 — второй таргет, не начат

Подробный список реализованного и отложенного — в `docs/roadmap.md`.

## Установка

### Для игроков

1. Установи **Thaumcraft 4: Reforged 1.2** или новее для Minecraft 26.3
2. Скачай `forbidden-magic-0.574-26.3-port.x.x.x.jar` из релизов
3. Положи jar в папку `mods/`

Если хост ещё не выпустил версию с API аспектов, потребуется собрать хост из исходников с патчами — см. раздел «Для разработчиков».

### Для разработчиков

**Требования:**
- Java 25
- Python 3.10+
- Git

**Сборка:**

```bash
# Клонируй хост рядом с портом
git clone <thaumcraft-4-reforged> ../thaumcraft-4-reforged

# Подготовь хост (применит патчи и опубликует локально)
python tools/prepare_host.py

# Собери порт
./gradlew build
```

Артефакт: `build/libs/forbidden-magic-0.574-26.3-port.0.1.0.jar`

**Тесты:**

```bash
./gradlew runGameTestServer
```

Все 48 тестов должны пройти.

## Использование

### Исследования

Открой Thaumonomicon и найди категорию **FORBIDDEN**. Начни с исследования «Сетевые осколки» (`NETHERSHARDS`) — оно открывается автоматически. Дальше изучай `HELLFIRE`, `SKULLAXE`, зачарования и растения.

### Осколки грехов

Осколки падают с существ по правилам оригинала:
- **Гнев** — за убийства мобов
- **Гордость** — с боссов (иссушитель, дракон)
- **Лень** — за смерть без участия игрока
- **Жадность** — за добычу с зачарованием Looting
- **Зависть** — с зомби-свинозверя с осколком в руке

### Хамелеоновы инструменты

Четыре инструмента (кирка, меч, лопата, топор) с тремя переключаемыми наборами зачарований.

- **Переключение:** Shift + ПКМ (стоит 5 прочности)
- **Ремонт:** осколок зависти на наковальне

### Конфигурация

Файл: `config/forbiddenmagic-startup.toml`

- `no_lust = true` — убирает аспект `luxuria`, осколок lust и связанные рецепты. Значение должно совпадать на клиенте и сервере.
- `enchanting = false` — отключает эффекты, исследования и рецепты зачарований.

### Thaumic Tinkerer

При установленном Thaumic Tinkerer Reforged стоимость восьми FM-зачарований появляется в его энчантере.
